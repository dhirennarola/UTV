Backup and restore

Bills are saved in this browser on this computer. Download a backup file to keep them safe or to move them to another computer. Restore adds bills from a backup file and never deletes existing ones.

Settings

Bill number format is like iVenus: PREFIX/FINANCIAL-YEAR/RUNNING-NO, for example GJ/2627/0455. The running number starts again at 0001 each April.

Google Sheet (saves bills online, opens on any device)

Paste the web app link and the secret from the Google Sheet setup. Every saved bill is then also written into the sheet, and this page loads the bills from the sheet. Enter these once on each computer.
